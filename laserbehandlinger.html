Behandlingsguide

Laserbehandlinger

Ulike lasere brukes til ulike formål. Det avgjørende er bølgelengde, energi, hudtype, indikasjon og behandlerens kompetanse – ikke bare merkenavnet.

Candela, CO₂, Fotona, Fraxel og andre teknologier

Candela GentleMax Pro / Pro Plus

Kombinerer vanligvis alexandrittlaser (755 nm) og Nd:YAG-laser (1064 nm). Brukes særlig til hårreduksjon og enkelte pigment- og karindikasjoner, avhengig av modell og innstillinger.

CO₂-laser

Ablativ laser (10 600 nm) for hudfornyelse og enkelte arr og hudforandringer. Fraksjonert CO₂ brukes blant annet ved aknearr og solskadet hud. Lengre nedetid og risiko for pigmentforandringer enn mange ikke-ablative alternativer.

Les hele guiden →

Fotona

Produsent av blant annet Er:YAG- og Nd:YAG-baserte systemer, brukt til hudfornyelse og ulike estetiske indikasjoner. Fotona 4D er et markedsført behandlingskonsept, ikke én egen lasertype.

Les hele guiden →

Fraxel

Merke for fraksjonerte laserbehandlinger. Ulike Fraxel-systemer kan være ikke-ablative eller ablative og har forskjellige bruksområder.

Les hele guiden →

Cynosure PicoSure

Pikosekundlaser brukt ved blant annet tatoveringsfjerning og utvalgte pigmentindikasjoner. Egnethet avhenger av hudtype, pigment og enhet.

Candela Nordlys

Plattform som blant annet kan omfatte IPL-teknologi og fraksjonert laser, avhengig av konfigurasjon. IPL er lysbehandling, ikke laser.

Lumenis UltraPulse og AcuPulse

Kjente CO₂-lasersystemer brukt til ablativ hudfornyelse og andre indikasjoner.

Risiko og sikkerhet

Feil laser eller innstilling kan gi brannskade, arr, pigmentforandringer og øyeskade. Mørkere hudtyper krever særlig tilpasning. Spør om konkret apparat, bølgelengde, beskyttelse, forventet nedetid og komplikasjonshåndtering.

Viktig informasjon

Dette er generell informasjon og ikke medisinske råd. Behandlinger, godkjenninger og produktindikasjoner kan variere mellom land og versjoner. Velg kvalifisert behandler, få en individuell vurdering og spør om risiko, alternativer og oppfølging.
